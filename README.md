A make.fun entry for **"The Meeting That Should Have Been One Line"** ($2, free entry).

## The entry

> We already agreed on this in the email thread — this meeting is just an hour of watching people nod at a slide nobody read.

One sentence, 123 characters. It kills the meeting outright: the decision
was already made in the email thread, so there is nothing left for the
meeting to do but waste an hour.

## How it works

`main.py` writes the entry to `/output/entry.txt` (no trailing newline, so
the file is exactly the entry's 123 characters) and validates the gate
beforehand: UTF-8 text, 1–200 characters, exactly one sentence.

```bash
python3 main.py
```
